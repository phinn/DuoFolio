How to read EPUB files on an iPhone

An iPhone can read EPUB files perfectly well. What usually goes wrong is not the reading — it is one of three things: the file never lands where the phone can see it, the file turns out to be DRM-locked, or it is not really an EPUB at all.

This guide covers all three, then the part specific to iPhone Duo: getting a book to open as a genuine two-page spread instead of one long column.

Step 1 — Get the file where the phone can see it

Every route ends up in the same place: the Files app. Pick whichever is least annoying.

  • iCloud Drive — drop the EPUB into iCloud Drive on a Mac or PC and it appears under Files → iCloud Drive on the phone. Best for a batch of books.
  • AirDrop — from a Mac, right-click the file → Share → AirDrop. The phone offers to open it in an app immediately.
  • Email or a message to yourself — tap the attachment, then the share icon, then Save to Files.
  • Direct download — Safari will hand the file to the share sheet. Choose Save to Files rather than opening it in place.

The most common failure: tapping the EPUB inside Files opens a preview, not a reading app. A preview has no library, no progress memory and no typography settings — which is why people conclude "it doesn't work properly". Use the share sheet to hand the file to a reader instead.

Step 2 — Check for DRM before blaming the app

This is the part most guides skip, and it is the reason a large share of "the app won't open my book" complaints exist.

EPUBs sold by Amazon Kindle, Kobo and Google Play are wrapped in DRM. The file is encrypted so that only the seller's own software can decrypt it. No third-party reader on iOS is permitted to break that, and none legitimately can. If your book came from one of those stores, the answer is their app, not a reader.

Books that will open anywhere:

  • Anything from Project Gutenberg — public domain, EPUB download is one click.
  • Anything from Standard Ebooks — public domain, but professionally typeset. Noticeably better source files than most commercial EPUBs.
  • Most independent publisher and direct-from-author sales, which frequently ship DRM-free.
  • Books you exported yourself from a document you wrote.

To check quickly: an EPUB is a ZIP archive. On a computer, rename the extension to .zip and try to open it. If it opens and you can see a META-INF folder, the book has no DRM and is structurally valid. If it refuses to open, it is locked.

Step 3 — Convert MOBI, AZW3 or PDF with calibre

Older Kindle formats and assorted e-book files convert cleanly with calibre, which is free and runs on macOS, Windows and Linux.

  1. Install calibre and drag the book into the library window.
  2. Select the book, then click Convert books.
  3. Set the output format to EPUB and confirm. For a large batch, use Bulk convert instead.
  4. Right-click the converted title → Open containing folder, and copy the EPUB to iCloud Drive.

Calibre will refuse to convert a DRM-protected book, which is itself a useful diagnostic: if the conversion fails immediately with an error about DRM, you have your answer about the file.

Step 4 — On iPhone Duo, ask for a spread, not a column

On a normal iPhone, a reader has one sensible layout: one column of text. A foldable has a second option, and it is the one that makes the device worth reading on.

Hold the Duo open and turn it sideways. A reader that was built for the fold will put even pages on the left half and odd pages on the right, with the hinge sitting in the gutter between them — the same geometry as a paperback held open. A reader that was merely made compatible will instead stretch a single column across the whole inner display, which reads like a very wide phone rather than a book.

The difference is visible in one second, and it is the only test worth applying to any reader you are considering for this device. Our own comparison of the current options is here.

Common problems, briefly

SymptomCause
Opens but text is tiny and cannot be resizedThe book is a fixed-layout EPUB, common for comics and illustrated titles. Text size is baked into the page.
Opens as plain text with no formattingThe file is HTML or TXT renamed to .epub. Convert it properly with calibre.
Cover art missingOften stripped by calibre during conversion. Re-add it with Edit metadata before converting again.
Reading position lost after switching appsThe reader has no persistent library. Position memory is a reader feature, not an iOS one.
Refuses to open, with no errorAlmost always DRM. See step 2.
