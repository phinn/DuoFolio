# DuoFolio 真机待验 Checklist

> 模拟器(iPhone Duo 27.1)能验:排版/翻页/位置恢复/harness/cover 渲染管线日志。
> 模拟器不能验:真实折叠姿态、合盖外屏呈现、真机手势。以下逐项真机过,每项留验证结果。

## 1. 合盖书签卡(sceneAccessory)

| # | 项目 | 步骤 | 通过标准 | 结果 |
|---|------|------|----------|------|
| 1.1 | 书签卡呈现 | 打开书 → 合盖 | 外屏显示卡片:封面缩略+书名+作者+进度条+"第 N 面 · 共 M 面" | ☐ |
| 1.2 | 进度实时 | 阅读中合盖(非先退出再合) | 卡片页码=合盖前最后位置(≤0.5s 轮询误差) | ☐ |
| 1.3 | 翻盖解锁 | 合盖 → 锁屏 → 翻盖 | 回到阅读器,位置=合盖时位置,不弹密码(Keep Awake 语义待定) | ☐ |
| 1.4 | 无书状态 | 书库页合盖 | 外屏无卡片/不显示陈旧书签(coverState.isActive=false) | ☐ |
| 1.5 | 换书 | 读 A → 退出 → 读 B → 合盖 | 卡片显示 B,非 A | ☐ |
| 1.6 | 杀进程重开 | 阅读中杀 app → 重开 → 合盖 | 无残留 accessory;重开后卡片=恢复位置 | ☐ |
| 1.7 | 非阅读态合盖 | 系统桌面合盖 | 无 DuoFolio 内容出现在外屏 | ☐ |

## 2. 双屏对开阅读(展开态)

| # | 项目 | 步骤 | 通过标准 | 结果 |
|---|------|------|----------|------|
| 2.1 | 自动对开 | 竖持展开 90°→135° 旋转 | w>h×1.05 自动切双列,中缝阴影居中无偏移 | ☐ |
| 2.2 | 跨页步进 | 双列下连续左滑 | 每次翻一"张"(2 面),右页奇数列连续(11·12 → 13·14) | ☐ |
| 2.3 | 对齐吸附 | 从单列转对开(旋转中) | 当前页自动吸附到偶数列起点,左页=原页 | ☐ |
| 2.4 | 对开页码组 | 双列+呼出 Chrome | 底栏显示 "N·N+1"(左·右页),切竖屏消失 | ☐ |
| 2.5 | 手势翻页 | 左右滑/左上角返回 | 热区 30%,横竖屏均响应;与系统边缘返回手势不打架 | ☐ |
| 2.6 | 边界 | 第一张右滑/最后一张左滑 | 停在边界,无白屏/崩溃 | ☐ |
| 2.7 | 双列图文混排 | 含插图章节对开 | 图不跨中缝被切;caption 跟图同列 | ☐ |

## 3. 位置恢复

| # | 项目 | 步骤 | 通过标准 | 结果 |
|---|------|------|----------|------|
| 3.1 | 姿态切换恢复 | 对开读到 N·N+1 → 合盖展开 | 恢复到同一张,单列=左页面码 | ☐ |
| 3.2 | 杀进程 | 阅读中杀 app → 重开 → 开同一本 | 回到 spine+page(321 制),误差≤1 面 | ☐ |
| 3.3 | 换字号回流 | 大字号读 p20 → 改字号 | 回流后仍在当前章节合理位置,不跳章 | ☐ |

## 4. 真机专属风险

| # | 项目 | 说明 | 结果 |
|---|------|------|------|
| 4.1 | cover 外屏色域/圆角 | 466×678pt 是模拟器推算值,真机量实际 safe area,卡片内容不被圆角裁 | ☐ |
| 4.2 | 合盖唤醒延迟 | 翻盖→app 前台→渲染首帧时长(WebKit 冷启 <1.5s 目标) | ☐ |
| 4.3 | sceneAccessory 与系统冲突 | 合盖时锁屏控件/音乐卡与书签卡的优先级表现 | ☐ |
| 4.4 | 外屏常显功耗 | 合盖阅读 30min 电量与发热基线 | ☐ |
| 4.5 | haptics | 翻页一张完成时轻触反馈(待加) | ☐ |

## 附:模拟器回归 harness(真机前必跑)

```bash
# 直开书(位置恢复链)
xcrun simctl launch <UDID> com.kinet.duofolio -duofolio.openIndex 0
# 横屏+自动翻 3 张(对开跨页链)
xcrun simctl launch <UDID> com.kinet.duofolio -duofolio.openIndex 0 -duofolio.landscape -duofolio.flip 3
# 验证:log 中 JS resize cols=2 → engine pos page 0→2→4→6(偶数对齐)
# 截图:simctl io <UDID> screenshot --display=1(内屏;默认 display 是外屏黑屏别误判)
```
